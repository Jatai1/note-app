# Note App

A simple note-taking app built with vanilla JavaScript. Notes are saved in the browser, so they are still there after a refresh.

git@github.com:Jatai1/note-app.git

## Features

- Add a note
- Delete a note
- Notes persist across page refreshes using localStorage
- Empty notes are blocked

## Tech

HTML, CSS, JavaScript (no frameworks)

## What I practiced

- DOM manipulation (querySelector, createElement, appendChild)
- Event listeners
- Arrays and objects (each note has a unique id)
- Array.filter to remove items
- localStorage with JSON.stringify / JSON.parse

## How to run

Open `index.html` in a browser.
